v2 검증: Python 문법 검사 및 모의 oneM2M HTTP 서버 기반 통합 테스트 통과.
- 10행 데이터셋 2회 순환, 총 20개 측정값 및 대응 분석 결과 전달
- MN/IN 합계 CIN 80개 확인
- 이상 판정, 동일 실행 재시작 시 중복 방지, 새 replay-id 확인
- 현재 UTC timestamp 생성, 순환 시 새로운 sample_id 확인
- 전송 대기 payload SQLite 보존 및 성공 시 원자적 체크포인트 갱신
- IN 데이터와 분석 결과 sample_id 매칭
실제 사용자 VM의 ACME/MEC 연동과 실시간 5초 간격은 이 테스트에서 검증하지 않음. 통합 테스트에서는 대기 간격 0을 사용함.

대시보드 UI 업데이트 검증:
- 모의 결과를 이용한 알림 10개 상한, 동일 sample_id 중복 방지, 오래된 알림 교체 통과
- 통신 오류 시 마지막 데이터 캐시 유지 통과
- Python 문법 검사 통과
- 실행 환경의 Chromium 제한으로 실제 브라우저 렌더링/모바일 시각 검증은 완료하지 못함
