# Authenticated transport

HTTP: run `python apps/secure_gateway.py --backend http://127.0.0.1:8081 --cert SERVER.crt --key SERVER.key --ca CA.crt --bindings bindings.json --host 0.0.0.0 --port 8443` for each CSE. Bind the plaintext CSE to loopback or otherwise isolate it; exposing the backend bypasses authentication. The gateway verifies client certificates and maps certificate CNs to allowed X-M2M-Origin values using `http-bindings.example.json`. Narrow the admin bootstrap list to actual registered identities. ACP enforcement still occurs at the CSE.

Set HTTPS QF_MN_URL/QF_IN_URL, QF_HTTP_CA_FILE and QF_HTTP_IDENTITIES_FILE on each application. The identities JSON maps each allowed Originator to `{"cert":"/private/client.crt","key":"/private/client.key"}`. Runtime apps should receive only their own key and mapping entry. Admin provisioning needs its explicitly authorized bootstrap identities. Authenticated HTTP refuses plaintext URLs and does not follow redirects. Without an identities file legacy development mode remains available.

Notifications: set QF_NOTIFY_CERT_FILE, QF_NOTIFY_KEY_FILE, QF_NOTIFY_CA_FILE and comma-separated QF_NOTIFY_PEERS (allowed CSE certificate CNs); advertise an https notification URL. Configure the CSE's outbound notification client to present a trusted certificate and trust this notification server. Unconfigured CSE clients will fail the TLS handshake; do not silently downgrade notifications.

MQTT: use mqtts URLs and QF_MQTT_CA_FILE. Username/password credentials require TLS. Optional QF_MQTT_CERT_FILE and QF_MQTT_KEY_FILE enable client certificates. `mosquitto.conf.example` and `mqtt.acl.example` implement mTLS certificate identity and least-privilege topics; replace paths and CSE IDs. Configure the ACME MQTT client with its own trusted client key. The broker binds authentication to topic ACLs; the CSE continues to enforce ACP. Never share runtime keys with the admin or expose anonymous/plaintext broker listeners.

No CA private keys, passwords, certificates, or deployments are committed. Obtain certificates from the deployment CA with server SANs matching actual DNS/IP and client identities matching configured bindings. Keep CA signing keys separate; limit key permissions and rotate/revoke compromised identities. Example files require deployment-specific edits.

Verification: ordinary unittest discovery performs a real local mTLS gateway handshake, blocks Originator spoofing and rejects missing/untrusted certificates. `QF_RUN_BROKER_TLS=1 python -m unittest discover -s tests -p test_mqtt_tls.py -v` requires amqtt 0.11.3/passlib and exercises a real TLS broker with password failures and publish/subscribe ACL denial. Temporary one-day test certificates are generated with OpenSSL and removed. The tests cover local authentication mechanisms. Deployment configuration and production PKI require separate verification.
